# Demonstração expira sem depender do agendamento

A demonstração dura 2 horas, mas no plano grátis da Vercel a rotina agendada só roda uma vez por dia. Por isso o prazo é conferido no próprio acesso (a regra do banco recusa empresa vencida), os dados vencidos são apagados de verdade sempre que uma demonstração nova é criada, e a rotina diária só limpa o que sobrar. Ninguém acessa uma demonstração vencida, mesmo que os dados ainda não tenham sido apagados.
